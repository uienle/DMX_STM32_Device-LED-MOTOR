# DMX Device — STM32 DMX512 Receiver Firmware

**Embedded Firmware | STM32F103C8T6 | C | DMX512 | RS-485 | PWM**

[English](#english) | [Tiếng Việt](#tiếng-việt)

## English

### Overview

This project implements the DMX512 receiver firmware for devices integrating an STM32F103C8T6 microcontroller and an RS-485 transceiver.

A DMX Device, such as an RGB LED or motor-control device, integrates a receiver circuit that receives DMX512 control data and drives the device's outputs. RS-485 provides the physical-layer interface for data transmission, while the firmware receives and processes data according to the DMX512 protocol.

All DMX Devices connected to the same DMX512 data line receive the same data stream. The firmware selects the relevant channel values based on the configured DMX address and passes them to the corresponding output functions. Each DMX channel carries an 8-bit value in the range of 0–255, which is used for PWM output control.

The same receiver firmware supports both RGB LED and motor-control devices. An RGB LED uses three DMX channels for red, green, and blue control, while a motor-control device uses one channel. The DMX Controller handles the system-level control algorithm and generates the channel values used to coordinate multiple devices.

### System Architecture

- **DMX Controller:** Executes the control algorithm and transmits DMX512 channel data.
- **DMX Device:** Integrates a DMX512 receiver circuit to receive control data and drive its outputs.
- **RGB LED Device:** Uses three DMX channels to control red, green, and blue output levels.
- **Motor-Control Device:** Uses one DMX channel for motor control.

Each device processes the channel values relevant to its configured DMX address. Multiple devices can be coordinated through the channel data generated by the DMX Controller.

### Receiver Processing Flow

1. Receive the DMX512 data stream through the RS-485 interface.
2. Process the received data according to the DMX512 protocol and store channel values in a buffer.
3. Select the channel values corresponding to the configured DMX address.
4. Pass the selected values to the corresponding output functions for PWM control.

**Data flow:** RS-485 Interface → DMX512 Reception and Processing → Channel Buffer → Channel Selection → PWM Output Control

### Key Features

- DMX512 data reception through an RS-485 physical-layer interface.
- Buffer-based storage of received DMX channel values.
- Channel selection based on the configured DMX address.
- Shared receiver firmware for RGB LED and motor-control devices.
- One-channel output handling for motor control and three-channel output handling for RGB control.
- 8-bit output control values ranging from 0 to 255 for PWM control.

### Hardware and Development Tools

- **Microcontroller:** STM32F103C8T6
- **Physical Interface:** RS-485
- **Communication Protocol:** DMX512
- **Output Control:** PWM
- **Programming Language:** C
- **IDE:** STM32CubeIDE
- **Firmware Library:** STM32 HAL

## Tiếng Việt

### Tổng quan

Dự án triển khai firmware nhận DMX512 cho các thiết bị tích hợp vi điều khiển STM32F103C8T6 và bộ thu phát RS-485.

Một DMX Device, chẳng hạn như thiết bị LED RGB hoặc thiết bị điều khiển motor, tích hợp mạch nhận DMX512 để tiếp nhận dữ liệu điều khiển và điều khiển các đầu ra của thiết bị. RS-485 cung cấp giao tiếp ở lớp vật lý cho việc truyền dữ liệu, trong khi firmware nhận và xử lý dữ liệu theo giao thức DMX512.

Tất cả DMX Device kết nối trên cùng một đường truyền DMX512 đều nhận cùng một luồng dữ liệu. Firmware chọn các giá trị kênh tương ứng với địa chỉ DMX được cấu hình và truyền chúng đến các hàm điều khiển đầu ra. Mỗi kênh DMX mang một giá trị 8-bit trong khoảng 0–255, được sử dụng để điều khiển đầu ra PWM.

Thiết bị LED RGB và thiết bị điều khiển motor sử dụng chung firmware nhận dữ liệu. LED RGB sử dụng ba kênh DMX để điều khiển ba thành phần màu đỏ, xanh lá và xanh dương, trong khi thiết bị điều khiển motor sử dụng một kênh. DMX Controller đảm nhiệm thuật toán điều khiển tổng thể và tạo ra các giá trị kênh để phối hợp hoạt động của nhiều thiết bị.

### Kiến trúc hệ thống

- **DMX Controller:** Thực thi thuật toán điều khiển và truyền dữ liệu các kênh DMX512.
- **DMX Device:** Tích hợp mạch nhận DMX512 để tiếp nhận dữ liệu điều khiển và điều khiển các đầu ra của thiết bị.
- **Thiết bị LED RGB:** Sử dụng ba kênh DMX để điều khiển mức đầu ra của ba thành phần màu đỏ, xanh lá và xanh dương.
- **Thiết bị điều khiển motor:** Sử dụng một kênh DMX để điều khiển motor.

Mỗi thiết bị xử lý các giá trị kênh tương ứng với địa chỉ DMX được cấu hình. Nhiều thiết bị có thể được phối hợp hoạt động thông qua dữ liệu kênh do DMX Controller tạo ra.

### Luồng xử lý dữ liệu nhận

1. Nhận luồng dữ liệu DMX512 thông qua giao tiếp RS-485.
2. Xử lý dữ liệu nhận được theo giao thức DMX512 và lưu các giá trị kênh vào buffer.
3. Chọn các giá trị kênh tương ứng với địa chỉ DMX được cấu hình.
4. Truyền các giá trị đã chọn đến các hàm điều khiển đầu ra để điều khiển PWM.

**Luồng dữ liệu:** Giao tiếp RS-485 → Nhận và xử lý DMX512 → Buffer kênh → Chọn kênh → Điều khiển đầu ra PWM

### Tính năng chính

- Nhận dữ liệu DMX512 thông qua giao tiếp vật lý RS-485.
- Lưu các giá trị kênh DMX nhận được vào buffer.
- Chọn kênh dựa trên địa chỉ DMX được cấu hình.
- Sử dụng chung firmware nhận dữ liệu cho thiết bị LED RGB và thiết bị điều khiển motor.
- Xử lý đầu ra một kênh cho motor và ba kênh cho LED RGB.
- Sử dụng giá trị điều khiển 8-bit trong khoảng 0–255 để điều khiển đầu ra PWM.
